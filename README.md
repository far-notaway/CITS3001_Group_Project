# CITS3001_Group_Project
The CITS3001 Project for 2026 will require you to work in teams of four or five to build a programming contest similar to LabTest1 or LabTest2.

The requirements are:

Each person in the team should produce one programming problem in the problemtools format (https://github.com/Kattis/problemtools)
 Each problem should have the following components:
title, capturing the essence of the story.
description, written as a tex file, that sets the problem in some story, along with a precise specification of input and output format. The problem should require an algorithmic solution, based on an algorithm or technique that appears in CITS3001 lectures. (You may ask for approval to use alternative algorithms). 
set of solutions written in python, including intended correct solutions, as well as naive solutions that are intended to fail (time out or wrong answer due to a false assumption) 
some sample data provided according to the specification, that can be used to test an algorithm prior to submission.
some secret data to test the correctness of the submission.
meta-data listing time limits and other context for the problem.
Each person in the team should produce a 1 page solution description, giving a high level description of the intended solution, as well as a time and space analysis. The solution description should also include an honest declaration of AI use, explaining how AI models were used to help build the problem and solution.
Each person in the group should attempt every other problem of the people in that group, and provide 
at least one attempted solution (it does not need to be correct).
a critical assessment of the difficulty of that problem, and suggestions for improvement.
